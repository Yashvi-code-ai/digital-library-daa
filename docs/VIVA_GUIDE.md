# Viva guide

**Binary vs linear search:** halving a sorted interval gives O(log n), while scanning gives O(n). **Merge vs quicksort:** merge guarantees n log n and is stable but uses n extra memory; quicksort is often in-place and fast on average but degrades to n². **KMP:** prefix function avoids repeating comparisons. **Dijkstra/Bellman-Ford:** Dijkstra needs nonnegative weights; Bellman-Ford supports negative edges and detects reachable negative cycles. **Prim/Kruskal:** grow a tree versus globally selecting safe edges with DSU. **DP:** reuse overlapping subproblem results. **Backtracking/B&B:** prune infeasible paths versus prune paths whose optimistic bound cannot beat best. **Ford-Fulkerson:** augment residual paths by bottleneck capacity. **Bipartite matching:** assign distinct right-side resources. **Huffman and Strassen:** not implemented in this current branch. **Master theorem:** applies to regular divide-and-conquer recurrences such as merge sort, not arbitrary input-dependent splits. **P/NP:** see complexity report. Be candid about missing components listed in compliance.
