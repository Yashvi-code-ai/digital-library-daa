# Demonstration script

1. Build and run with data/small; browse the sample catalogue.
2. Search by title, author, category, keyword and ID.
3. Search a pattern using KMP and Rabin–Karp; explain prefix fallback and rolling hash verification.
4. Recommend books for user 1; show that previously read books are filtered and explain the interest/citation/rating score.
5. Open the algorithm workbench and demonstrate sorting, string matchers, knapsack, Dijkstra and CRT.
6. Run the Merge-vs-Quick benchmark and inspect the measured CSV.
7. Run with data/large and discuss linear catalogue-search cost.

A full capacity-shock scenario using flow/matching is not currently exposed through the CLI and must be completed before presenting it as an implemented demonstration.
