# Demonstration script

1. Browse small catalogue.
2. Search by title, author, category, keyword and pattern.
3. Compare string matchers.
4. Generate recommendations for user 1 and explain the deterministic score.
5. Run workbench knapsack, Dijkstra and CRT examples.
6. Execute sorting benchmark and discuss its machine dependence.
7. Repeat with large synthetic dataset; explain current linear catalogue scans.

A capacity-shock end-to-end scenario is not yet exposed by the CLI.
