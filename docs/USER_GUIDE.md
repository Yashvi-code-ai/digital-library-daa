# User guide

Build with CMake and C++17: `cmake -S . -B build && cmake --build build`. Run `ctest --test-dir build --output-on-failure`. Start the CLI with `./build/digital-library data/small` (pass `data/medium` or `data/large` for larger catalogues). Menu actions: browse, search, recommend, algorithm workbench, sorting benchmark. Synthetic data only; no external dataset provenance is claimed.
