# Algorithm mapping

| Algorithm family | Application mapping |
|---|---|
| Merge/Quick sort, binary search | Sort and locate catalogue key/score arrays; binary search requires sorted data. |
| Naive, Rabin–Karp, KMP, finite automaton | Search title, author and description text. |
| Dijkstra, Bellman–Ford, Floyd–Warshall | Weighted citation or knowledge graph path analysis. |
| Prim, Kruskal | Minimum-cost backbone for a weighted knowledge graph, not a recommendation score. |
| Ford–Fulkerson, bipartite matching | Allocate capacity-limited copies/resources to readers. |
| 0/1 knapsack variants | Select books under a storage or reading-time budget. |
| N-Queens | Syllabus constraint-satisfaction workbench; no artificial library mapping. |
| CRT | Reconstruct a modularly partitioned counter/hash demonstration. |

Some syllabus algorithms are not implemented yet; consult COMPLIANCE.md. State when an algorithm is a workbench exercise rather than forcing an inaccurate product analogy.
