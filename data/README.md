# Dataset provenance

All data are illustrative synthetic teaching records, not scraped or attributed to a real library. The small set contains 10 sample books and three readers. The medium catalogue contains 100 deterministic generated records and the large catalogue contains 1,000. The adversarial set includes an intentionally blank title (the domain validator must reject it) and repeated-pattern text. Generated fields follow deterministic modular patterns based on each record ID. Lists inside fields use the pipe character. No real-world source is claimed.
